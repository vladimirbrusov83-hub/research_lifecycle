What "agentic" actually means

One request, many helpers

A chatbot answers a question and stops. An agentic tool takes a whole job, splits it into parts, hands each part to a helper, then looks at what came back and runs it again. Here is what that looks like in the three phases where it changes the work most.

02 · Literature Review

“Find what has already been published on my question.”

One assistant takes the request and splits it up
searches the databases reads each paper and writes a summary lays all the summaries side by side in one table
New papers keep appearing, so it runs the whole search again.

06 · Data Analysis

“Run the analysis on this dataset.”

One assistant takes the request and splits it up
writes the analysis code and runs it reads its own error messages and fixes them draws the figures and checks the statistics
It keeps going until the analysis runs clean.

07 · Interpretation & Writing

“Turn these results into a draft.”

One assistant takes the request and splits it up
drafts each section of the paper checks every claim against the actual results puts the citations into the right format
Each round of criticism sends it back for another pass.
The assistant that takes your request The helpers it hands the pieces to ↻It checks the work and goes around again

What none of it does: decide whether the question was worth asking, or what the answer means. That stays with the researcher.

The honest part

Where the lanes overlap: suggestion, or record?

Agentic AI reaches onto library turf in four phases. The split isn't clean, so ask a sharper question: is the output a suggestion, or a record that has to stand up in review?

Phase 02 · Literature Review

Both claim to "find everything, rigorously." The agent retrieves; the library's PRISMA protocol is the auditable method of record.

The floor an agent can't reach

Four things only the library can do

Not a services list, but the structural capabilities no model has, by construction. This is the budget case and the reassurance in one.

01

Licensed access

The corpus behind the paywall

An agent can only reason over what it can reach. Subscribed databases and archival holdings are reachable because the institution licenses them.

02

Permanence

A DOI that resolves in 30 years

Preservation is a commitment across time, not an output. Repository deposit and archival access outlive any model or funding cycle.

03

Authority

Determinations that must stand

A predatory-journal call or integrity finding has to hold up in tenure, funding and misconduct review. An agent's opinion has no standing there.

04

Neutrality

No optimization target

Agentic tools are tuned toward an objective: acceptance, engagement, novelty. The library isn't optimizing for anything but the researcher's aims.
